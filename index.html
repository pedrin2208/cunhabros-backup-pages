CunhaBros Backup

O CunhaBros Backup é uma ferramenta privada de backup e recuperação utilizada para proteger dados do sistema interno CunhaBros Gestão.

A integração com o Google Drive é utilizada exclusivamente para armazenar e verificar cópias de segurança criptografadas, mediante autorização do titular da conta Google.

O aplicativo não oferece acesso público aos arquivos armazenados.
